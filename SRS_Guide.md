# StudyBearer Software Requirements Specification (SRS) Guide

## 1. Overview
**Project Name:** StudyBearer
**Version:** 1.0
**Target Event:** iSITE AI Hackathon 2026

StudyBearer is an AI-powered educational workflow application. It automates study planning and testing by transforming passive course materials into an active, scheduled, and gamified learning pipeline.

## 2. Architecture & Tech Stack
- **Frontend:** Astro & React (Islands architecture)
- **Backend & Auth:** Supabase (PostgreSQL, Storage, Google OAuth)
- **Database ORM:** Prisma
- **AI Orchestration:** n8n (handles webhooks, AI agent routing with OpenAI/Gemini, and Calendar sync)

## 3. Core Features
### 3.1 Authentication
- Google OAuth via Supabase to access Google Calendar APIs.
- Base profile creation initializes `current_streak` to 0 and base competitive tier.

### 3.2 Document Intake & Processing
- Upload PDF documents to Supabase storage.
- Capture user parameters: desired total study hours, target completion date, preferred study days.
- Trigger n8n webhook on upload.

### 3.3 n8n AI Orchestration & Calendar Sync
- Extract raw text from uploaded PDF.
- Chunk curriculum into a structured JSON array of daily learning objectives via AI.
- Push chunked objectives to Google Calendar as timed events.
- Event descriptions contain specific sub-topics.

### 3.4 Gamified Assessment Engine
- Quizzes unlock after the scheduled calendar event time passes.
- Dynamic JSON payload generated by n8n webhook containing MCQ, Enumeration, and Identification questions.
- React frontend renders questions interactively with immediate feedback.

### 3.5 Progression & Gamification Logic
- **Streaks:** Completing study and passing quizzes adds +1 to `current_streak`. Missing a 24-hour window resets it.
- **Elo/Points:** Awarded based on quiz accuracy and streak multipliers.
- **Ranks:** Tiered ranks (e.g., Warrior, Elite, Master, Grandmaster, Epic, Legend, Mythic) update automatically.
- **Achievements:** Cosmetic unlocks (e.g., "First Blood", "Flawless Victory").

## 4. Design Aesthetics
- **Vibe:** Dark-toned, cinematic, and moody visual aesthetic. Deep blacks, high-contrast typography, and subtle glowing neon accents (Glass-Neon aesthetic).
- **Dashboard:** Visual roadmap of chunked PDF (locked, current, completed).
- **Animations:** High-fidelity CSS/React-spring animations for rank-ups and unlocks.

## 5. Non-Functional Requirements
- **Performance:** Astro initial load under 1.5s. n8n processing under 30s.
- **Security:** RLS for PDFs in Supabase. Google Calendar tokens handled securely.
- **Reliability:** n8n workflows include error-handling nodes (Catch nodes) for AI hallucinations or rate limits.
- **Maintainability:** Prisma Client for strict type-checking.
